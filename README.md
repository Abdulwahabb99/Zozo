# For Zozo 💛

A tiny single-page surprise: a few sweet questions, then an invitation to a movie car date.

## Run it

```bash
npm install
npm run dev      # local dev server (open the "Network" URL on your phone)
npm run build    # static site in dist/ — upload anywhere (Netlify, Vercel, GitHub Pages…)
npm run lint
```

## Where to edit

- **Words:** `src/content.js`
- **Colors & fonts:** the variables at the top of `src/index.css`
- **Steps / flow:** `src/App.jsx`
- **Pieces:** `src/components/` (the sad popcorn buddy, date-plan ticket, balloons and confetti)
